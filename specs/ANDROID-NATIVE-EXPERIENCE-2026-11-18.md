# Android 原生体验优化

保留用户已经确认的 Android 页面框架：照片、备份、活动、设置四栏，以及现有内容分区和入口位置。照片筛选仍为全部、未备份、已备份；传输到电脑仍在设置中紧接活动记录；活动右上角仍保留更多菜单。

本轮版本为 `2.0.0-alpha.4` / versionCode `4`，功能源码提交为 `d057bddb76ff6113bdc8cce5d44ac126888ba6ca`，位于 `feat/mobile-framework-parity`。本记录取代 alpha.3 的后续安装安排：**用户已明确要求手机离线后只编译，不安装；30 分钟自动安装任务已停用。**

## 完成范围

- 原生控件：Material 单选对话框、整行单选/复选/开关、48 dp 最小选择触控高度；移除父行与子控件的重复操作目标，保留禁用状态和危险操作提示。
- 导航状态：每个页面实例具有独立保存键；标签切换保留各自页面及表单状态，再次点击当前标签返回该栏首页；已弹出页面的状态及时回收。异步保存完成后仅返回原页面，避免误跳转当前标签。
- 输入体验：键盘避让、输入时隐藏底栏、切页清理焦点、数字与地址键盘、输入范围提示；高级配置、任务连接策略和归档天数草稿支持保存恢复。凭据和订阅内容不写入界面恢复 Bundle。
- 辅助功能：标题语义、控件角色与选中状态、整行操作目标、照片缩放/重置辅助操作、随布局方向变化的返回图标与转场。
- 照片和分享：长按选择震动、缩略图失败占位、按媒体修改时间及大小更新缓存、双击缩放；系统分享附带 URI 读取授权，系统页面无法打开时提供反馈。
- 视频：离开前台暂停并保存播放位置；释放播放器；使用系统音频焦点、耳机断开处理和原生缓冲指示。播放器视图在播放源变化时更新绑定。
- 列表与弹窗：活动分组投影和日期格式缓存；归档选择使用惰性列表，并在提交时核对仍有效的选择；长文件名可滚动选择复制；日期范围弹窗适配较小窗口。
- 系统集成：网络和省电状态随系统回调更新；提供应用通知设置入口；相册权限请求不夹带通知授权；扫码提示遵循应用语言。
- 代理配置：用户点击后才读取剪贴板，处理无文本、读取失败和超大内容；提交时固定输入及配置 ID，避免等待其他工作完成时误用新页面内容。
- 本地化：英文与香港繁体粤语各 1425 条映射；静态清单 647 条中文源码字符串，缺失映射 0。
