# 面板动画及原生交互检查

Android `2.0.0-alpha.14`（14）/ iOS `0.2.37`（41）。iOS 构建来源 `2fe0d9829eaecea32a5a91ece8bf57ea5335acb7`；Android 随后追加系统返回与退出动画重叠的保护，完整来源见交付清单。

## Android 的根因与修复

原来的选择回调立即将 open/filename 等状态设为 false，导致 if 分支中的 ModalBottomSheet 在系统收起动画执行前就被移除。关闭按钮及全局 vm.sheet 清空也存在相同问题。

统一的 NativeModalSheet 保留面板实例，等待 Material SheetState.hide() 完成才卸载。单选面板先完成收起，再应用选项或执行后续动作；外部状态清空时也保留旧目的地到退出完成。返回、遮罩及下拉仍使用 Material 原生交互，未硬编码动画时长，遵守系统动画设置。

所有直接的 ModalBottomSheet 已统一到该宿主，覆盖上传画质、并发、语言、外观、配色、主题色、照片筛选/相册、媒体预览、详情/高级信息、完整文件名、归档选择、日志和保留的旧设置入口。真正的多选或日志范围切换会继续留在面板内，不强制关闭。

退出中防重复提交，取消的动画不执行旧回调；快速重新打开会使旧的退出失效。全局目的地退出后释放临时表单状态，避免长期保留输入中的凭据。

## 同轮检查与优化

| 范围 | 结果 |
| --- | --- |
| 长面板 | 标题及关闭按钮固定，正文独立滚动；高度按当前屏幕约束，避免横屏或大字体时关闭入口滚出视野 |
| 键盘 | 面板退出前清除输入焦点并收起键盘；系统文件/设置入口在面板退出后打开 |
| 日志导出 | 面板退出后再打开日期选择器，取消日期选择返回原面板；导出选择器在退出后启动；保留非敏感的日期/显示状态以适应旋转 |
| 文件名 | 复制后显示「已复制」，不额外叠加系统剪贴板通知；关闭入口与其他面板一致 |
| 活动移除 | 补齐上一轮遗漏的左滑确认过滤，已取消任务不再被旧 pending 集合拦截 |
| Android 其他入口 | 检查四标签导航、照片缩放/视频生命周期、扫码相机启停、系统返回和弹层层级；保留已有原生实现与已确认框架 |
| iOS 表单 | 账号凭据支持键盘提交并在连接前结束编辑；连接页、代理配置页支持滚动收键盘；代理表单补充键盘「完成」 |
| iOS 面板 | 备份范围补充明确关闭入口；文件名面板可展开到大高度并显示拖动指示；已有详情/高级信息的完成按钮保留，继续使用 SwiftUI 原生收起动画 |
