# 已取消任务无法移除修复

Android `2.0.0-alpha.12`（12）。

问题：活动页与批次页共用了「需要停止的任务」和「允许移除的未完成任务」的集合，两者均排除了 cancelled；左滑、任务详情和底层 itemAction 也排除了该状态。结果是取消后的任务持续显示，但没有可用的移除入口。

修复将「可暂停」与「可移除」分开：

- 已取消仍属于未完成记录，可以通过活动菜单、批次菜单、左滑或任务详情移除；暂停和继续仍不可用。
- 「未完成」筛选包含已取消任务；已完成/云端已有记录继续使用归档操作，不属于移除未完成的目标。
- 已取消项只通过带账号和状态条件的 SQL 更新 hidden 字段，不再次调用核心状态转换，不重启传输，不改变已有备份记录、云端回执或自动备份抑制记录。
- 批次移除兼容已取消项，全部可见项移除后，活动页不再展示该批次。保留历史数据及本机、云端照片。

iOS 的 unfinished 定义已包含未隐藏的已取消任务，移除逻辑正常，本轮不修改 iOS。

验证使用内存 Room 数据库和混合状态批次，覆盖全取消批次的可见性/移除条件、账号隔离、已取消记录隐藏后的证据保留，以及已完成或恢复执行的记录不会被取消项专用 SQL 误隐藏。不操作真实手机数据；本轮继续只编译、不安装。

针对性回归测试 `CancelledActivityRemovalTest` 3 项全部通过。
