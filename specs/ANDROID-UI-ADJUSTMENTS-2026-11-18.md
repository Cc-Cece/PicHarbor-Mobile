# Android 活动与照片界面调整

版本：`2.0.0-alpha.6` / versionCode `6`。继续保留现有四栏和页面分区。

- 活动列表、归档列表、批次内任务列表支持向左滑出操作按钮：已完成可归档，已归档可取消归档，未完成可移除。混合状态的批次只移除当前筛选内的未完成项，已完成项保留。
- 滑动本身不执行操作；移除前显示确认，保留本机和云端照片。列表同时仅展开一行，点击已展开的内容或按返回键可以收起。辅助功能提供同等操作入口。
- 照片右下角状态标志增加圆形底色：已备份绿色、备份中主题主色、异常主题错误色；图标使用对应的对比前景色。
- 活动、归档和批次右上角仅保留菜单图标，保留“活动选项”的辅助功能说明及原菜单操作。

未改动 iOS、共享业务核心、代理连接修复和数据库结构。英文及香港繁体粤语复用现有文案，无新增缺失映射。
