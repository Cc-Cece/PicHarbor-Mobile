# 备份主卡片对齐与自动备份状态

Android `2.0.0-alpha.7` / versionCode `7`；iOS `0.2.31` / build `35`。保留 alpha.6 的活动左滑操作、照片标志底色与仅图标菜单。

## 展示

- Android 备份进行中卡片使用与 iOS 相同的“当前速度 / 剩余大小”双列，不再将最近单个文件的速度和大小当作整体进度。
- 准备中包含准备与查询，上传中为上传阶段，确认中包含提交与确认。存在待处理任务时两端均保留阶段计数，包括暂时为 0 的阶段。
- 两端主卡片顶部均增加自动备份状态图标及文字：开启时勾选图标，关闭时暂停图标。状态直接跟随当前账号的真实设置；该标志只展示状态，不修改开关。

## 统计口径

- Android 使用单调时钟下的共享 8 秒字节窗口汇总并行及连续文件上传，初始样本不足时显示计算中；超过 3 秒没有新字节时速度归零。每秒刷新，离开页面停止计时。
- 剩余大小统计当前账号完整待处理队列，不受活动列表 10000 项上限影响；扣除各个在传文件已发送字节，提交、确认和已有云端标识的内容不重复计算。
- 未知大小明确显示计算中或至少已有大小。多资源任务尚未取得完整上传口径时，显示待计算项，不将一个资源的大小冒充整组大小。
- 任务结束、停止及账号切换清理传输采样，历史暂停、失败和取消项不会冒充正在上传的任务。保持数据库 schema 9，未修改共享 gpmc 核心及 Python 平台适配器。

## 验证

Android 新增 5 项统计回归测试并通过，覆盖并行汇总、队列剩余字节、确认阶段排除、未知及多资源大小、溢出、停传归零、连续文件速率与重置。复用现有英文及香港繁体粤语映射，无新增缺失文案。

Android 签名构建与 iOS macOS 构建分别验证；不为界面检查而启动真实照片备份或修改现有任务状态。30 分钟自动安装任务继续停用。
