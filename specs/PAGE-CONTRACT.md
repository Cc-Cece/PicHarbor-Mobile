# 移动端页面结构规范（实施前冻结）

蓝本：iOS `e0c495c9b23dba5b40eaff7e01b3acd597847096`。本轮只调整 Android 展示、导航及旧设置兼容，不扩大 iOS 产品范围。

用户已经确认左右对照预览，并明确修订三项：照片仅保留全部/未备份/已备份；「传输到电脑」移动到设置的活动记录之后；活动页保留清晰的更多菜单。下表基线中的电脑入口归属据此覆盖，不作为未通过项。

各行分别检查「内容与顺序」「入口与层级」「状态与操作」三项；实施前共 25 页、75 项。四个主页面的 12 项与关键路径必须全部对应，其余共同结构总通过率至少 95%。未知或缺少证据计未通过，不以本清单自动证明实际渲染正确。系统例外必须在对应行注明原因，不计为普通页面差异。

| 账号 | 本机账号列表/当前勾选 → 添加账号 → 切换进度 → 退出当前账号与保留历史说明；添加进入连接页 |

| 备份范围 | 全部可访问/相簿勾选 → 范围说明 → 数量/确认后自动备份/画质/Live Photo/网络 → 确认；账号与空范围门控 |

| 代理 | 本应用开关 → 配置与订阅入口/当前配置 → 选择策略 → 测速 → 节点结果与说明；不将导入表单放主设置页 |
| 代理配置列表 | 配置列表及激活/更新/详情 → 添加入口；空配置说明 |

| 代理配置详情 | 配置名/节点/状态 → 使用/更新/移除；秘密不显示 |
| 任务连接策略 | 跟随全局 → 自动/手动/主节点/备用/失败策略 → 保存及不改全局说明 |

关键路径：照片选择→确认→活动→任务；备份→范围→确认；设置→账号→连接；设置→代理→配置→添加；任务→连接策略；活动→归档；照片→预览→信息/分享。

导航：四个标签分别保留栈、筛选与滚动。弹层优先关闭，详情返回原页面；再次切换标签恢复原位置。Android 根页面返回遵循系统退出规则。原生控件、权限、后台、照片版本能力和系统分享器允许有明确平台差异。

2026-11-18 用户后续修订覆盖冻结表：高级配置仅自定义模式可见；「保留相册分类」替代单向相簿同步，Android 移除不具备原件版本能力的版本保留；Android 界面增加自动/手动 Material 配色。系统权限入口按未授权、有限访问和完整访问分别呈现。Google 头像成功获取时替换账号占位图。详见 [后续实现记录](ALBUMS-AVATARS-NATIVE-2026-11-18.md)。
