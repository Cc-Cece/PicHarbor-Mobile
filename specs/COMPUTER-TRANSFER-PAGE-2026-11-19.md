# 两端传输到电脑页面优化

Android 2.0.0-alpha.17（17），iOS 0.2.40（44）。保留 Material / SwiftUI 原生界面，统一连接、发送范围、状态、发送操作的层级。只编译、不安装。

- 扫码连接为主要按钮，从图片识别为次要按钮；增加简短的电脑端操作指引。iOS 直接提供图片识别入口，同时保留扫码页内的识图能力。
- 手动输入默认折叠，Android 展开有动画并为表单添加间距和内边距，避免输入框贴边及圆角裁切；iOS 使用原生 DisclosureGroup 和键盘完成按钮。
- 扫码或选择已保存电脑后显示目标地址与准备提示。连接信息不完整或发送范围为空时禁用开始按钮。
- 发送范围在本页独立选择，初始沿用当前备份范围；后续调整仅用于本次页面会话，不修改备份偏好、不要求 Google 登录。两端使用各自原生底部面板。
- Android 向已有传输流程传入本次选择的媒体 ID 快照，并保留 Live Photo 完整配对；空选或已消失的选项不回退为全库。电脑发起的 offer 范围解析不变。iOS 仍通过已有发送 API 传入所选 PHAssets。
- 开始/停止按钮占满可用宽度；没有传输时隐藏空状态区域，传输期间显示进度与计数；局域网、电脑确认和前台运行说明放在操作旁。
- 忘记电脑增加原生确认，清除当前选中的对应目标信息，不删除已发送文件。

验证包含 Android 选择范围、配对、面板生命周期及既有传输相关离线测试，iOS Python 离线套件、本地化检查、Android 签名 release 与 iOS 未签名 IPA 编译。详细结果及摘要见本轮 delivery 清单。未执行真实电脑传输或设备界面验收。
